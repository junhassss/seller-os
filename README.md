# SELLER OS v0.1

30만 원의 초기 실험 예산 안에서 남성 의류 상품 후보의 경제성과 검증 상태를 관리하는 한국어 로컬 MVP입니다.

## 기능

- 상품 후보 생성·조회·수정·삭제, 검색
- 공급처, 원가, 판매가, 배송비, 수수료율, 기타비용, MOQ, 이미지 권한, 재고 확인일, 샘플 검수 상태 관리
- 건당 기여이익 = 판매가 - 원가 - 배송비 - 판매수수료 - 기타비용
- 이익률 = 건당 기여이익 / 판매가 × 100
- 초기 투입액 = 원가 × MOQ + 배송비 + 기타비용
- 30만원 예산 사용·잔여 추적
- CSV 내보내기/불러오기, JSON 백업/복원, 브라우저 localStorage 자동 저장
- 초기 5개 상품은 모두 **검증 전 가정**이며 실제 소싱·재고·가격·권리 확인이 필요
- 공개 소싱 목록의 가격·MOQ·배송 근거와 원문 링크 표시
- 할인율·반품 충당률·건당 광고비를 조정하는 손익 민감도 분석

> 계산에서 제외: 부가세, 반품/교환, 광고비, 포장 인건비, 플랫폼별 추가비용. 이 앱은 주문을 실행하거나 이미지를 수집·업로드하지 않습니다.

## 실행

```bash
pnpm install
pnpm dev
```

브라우저에서 표시된 로컬 주소를 엽니다.

## 검증

```bash
pnpm test
pnpm build
```

## 데이터 주의

데이터는 현재 브라우저에만 저장됩니다. 중요한 변경 뒤에는 **백업** 버튼으로 JSON 파일을 내려받으세요. 초기화는 확인 대화상자를 거친 뒤 초기 5개 가정으로 되돌립니다.
